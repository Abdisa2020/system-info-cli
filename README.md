# sys-info-cli

A lightweight CLI utility providing instant machine and Node.js environment diagnostics.

## Installation

Run directly without installing:
\`\`\`bash
npx sys-info-cli
\`\`\`

Or install globally:
\`\`\`bash
npm install -g .
\`\`\`

## Usage

\`\`\`bash

# Standard formatted output

sys-info

# Machine-readable JSON output

sys-info --json
\`\`\`
